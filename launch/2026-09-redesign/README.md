# Agentarium preview film

[Watch the film](agentarium-launch.mp4).

This 36-second, 1080p film combines fictional Demo captures, the application artwork, and an original synthesized score. It is an edited walkthrough, not a continuous screen recording. All displayed tasks and evidence are synthetic. The screenshots have reduced-resolution content, so small UI text is softer than the running application.

The film demonstrates the local browser application. Codex is the tested native adapter; JSON and JSONL accept normalized local snapshots. It does not announce an available npm package or hosted service.

The typeface license is included in `FONT-LICENSE.txt`. Source artwork provenance is recorded in `public/assets/sculpted/` at the repository root. Working captures, draft posts, and editing intermediates are kept outside the source release.
