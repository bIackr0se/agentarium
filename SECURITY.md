# Security policy

Agentarium is a localhost-only, read-only application. Do not include
transcripts, credentials, absolute paths, or other private source metadata in a
report.

## Reporting a vulnerability

Use the repository's GitHub Security tab and private vulnerability reporting
form. Do not open a public issue for an unpatched vulnerability. Include a
concise description, affected commit or version, reproduction steps, and the
impact. Attach only sanitized, synthetic data.

If private vulnerability reporting is unavailable, open a minimal public issue
without secrets or exploit details and ask the maintainer for a private channel.
